

# 代码实现
## 1.成员变量
DataSearch有两个成员变量：emulator和data，
构造函数接收这两个参数，并调用hookReadAndWrite方法。这说明该类的主要功能是通过挂钩读写操作来搜索内存中的特定数据。

## hook方法
hookReadAndWrite方法，在这个方法中创建了ReadHook和WriteHook两个钩子。
读钩子在每次读操作时触发，调用searchData方法。
写钩子稍微复杂一些，为了检索写入后的数据，手动执行了写入操作，然后进行搜索。这样设计确保搜索的是最新的数据。

## searchData方法
在searchData方法中，搜索范围是地址前后64字节，然后调用searchMemory进行实际的内存扫描。
如果找到匹配项，就输出并启动调试器。这有助于快速定位数据出现的位置。

## searchMemory方法
searchMemory方法遍历指定内存范围，首先检查第一个字节是否匹配，如果不匹配则跳过，提高效率。
匹配整个数据块后，记录指针并跳过已匹配部分，避免重复检查。这种优化减少了不必要的内存读取，提升了搜索速度。
